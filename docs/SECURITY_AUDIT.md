# Анализ безопасности CryptoCore 0.8.2

Статическая проверка образовательного проекта, а **не внешний аудит**. Ниже указан текущий реализованный контроль и область его применимости.

| Область | Реализация | Остаточный риск / действие |
|---|---|---|
| Nonce и IV | SQLite-реестр для высокоуровневого GCM, EtM, файлового шифрования и `cli.encrypt_data` для режимов с IV. Атомарный unique index. | Не синхронизирован между устройствами; низкоуровневые примитивы не регистрируют IV; нельзя откатывать БД. |
| AES-GCM | Все рабочие высокоуровневые GCM-пути вызывают `PyCryptodome AES.MODE_GCM`, а не Python-GHASH. | Успех тестов не доказывает отсутствие аппаратных side channels. |
| Пароли | `getpass` и альтернативные источники; `--password` только с небезопасным opt-in. | `str`/`bytes` и другие копии могут оставаться в памяти; env/file требуют защиты. |
| Секретные ключи | Не выводятся по умолчанию; `--key-file`; приватное создание нового `.key`/`derive --output` без перезаписи. | Windows ACL зависит от каталога; `--show-key` раскрывает ключ. |
| Потоки | CLI блоками по 64 КиБ; временный файл и `os.replace`; GCM/EtM проверяют тег перед публикацией. | In-memory API не потоковый; TOCTOU и атаки на файловую систему могут требовать дополнительных механизмов. |
| PBKDF2 | Верхняя граница 1 000 000, CLI без opt-in 100 000, `dklen` ≤65 536. | Медленная Python-реализация создаёт нагрузку даже при лимитах; реальный сервис требует timeouts/budgets. |
| AAD | `--aad` HEX или `--aad-file` для обоих AEAD-режимов. | Изменение AAD приводит к отказу в расшифровании, файл AAD должен быть доступен обеим сторонам. |
| Низкоуровневые режимы | ECB/CBC/CFB/OFB/CTR и собственные SHA/HMAC/PBKDF2 оставлены как учебные. | Нельзя считать их схемами безопасного хранения данных; выберите аутентифицированный режим. |

### Тестовый статус

Пользовательский Windows-прогон **0.8.1**: 409 пройденных тестов, покрытие 94,69%. Отдельные тесты версии 0.8.2 должны быть повторно запущены на целевой машине. Наличие нового кода не заменяет независимый аудит или эксперимент 1+ ГиБ.

См. [подробную матрицу преподавательских замечаний](SECURITY_REVIEW_2026.md) и [политику безопасности](../SECURITY.md).


**Предварительный прогон 0.8.2 (Linux, Python 3.13, тестовый совместимый адаптер AES на основе `cryptography`):** 422 теста успешно пройдены, 95,40% общего покрытия строк и ветвей. Это не заменяет полный запуск с настоящим PyCryptodome на Windows; адаптер не входит в поставку.
