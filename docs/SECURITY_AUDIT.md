# Аудит безопасности CryptoCore 0.8.0

Это **статическая проверка по присланному ZIP**, не независимый криптографический аудит и не доказательство отсутствия уязвимостей. До запуска на целевой машине итоговый статус зависит от повторного тестирования.

| Объект | Наблюдение | Риск / рекомендация |
|---|---|---|
| Ключи | AES принимает 16-байтные ключи; в CLI есть демонстрационные ключи и печать случайного ключа | Не использовать фиксированные ключи в реальных данных; исключать их из журналов |
| RNG | `os.urandom` | ОС отвечает за энтропию; повтор nonce с ключом недопустим |
| GCM | Аутентификация через `secrets.compare_digest` до возврата plaintext | Проверить сохранение отсутствующего/существующего файла при неуспехе |
| EtM | Разделённые ключи шифрования и аутентификации; HMAC до CTR-расшифрования | Нельзя повторять nonce; доменное разделение специфично для CryptoCore |
| PBKDF2 | `dklen` ограничен 65536; число итераций в CLI не ограничено сверху | Потенциальный ресурсный DoS при недоверенных аргументах; вводить лимиты в сервисе |
| Память | Пароль/ключ CLI очищаются в `bytearray` в `finally` | Копии `str/bytes` могут существовать; нет гарантии zeroize |
| Файлы | Основной plaintext/ciphertext читается целиком | Для >1 ГБ возможен высокий расход RAM; хеш/AAD читаются по частям |
| GHASH | Реализован на Python с зависимыми от данных операциями | Нет гарантии constant-time; не применять для реальных секретов |
| CLI | Печать производного ключа — часть ТЗ; argv содержит пароль при `--password` | Использовать `--password-env`/`--password-file`, защищать stdout |
| Запись | `write_binary()` не является атомарной транзакционной записью | Ошибки диска могут оставлять частичный файл; применять временный файл и `os.replace` в production |
| Зависимости | Runtime — PyCryptodome; тесты — pytest и pytest-cov | Использовать проверенные версии и обновлять при публикации advisories |

**Не утверждается:** тесты >1 ГБ и полная систематическая проверка всех путей исполнения; они требуют отдельного запуска на подходящем устройстве. Векторные и сравнительные тесты подтверждают корректность только для покрытых сценариев.


## Дополнение v0.8.1 (после замечаний преподавателя)

Предыдущая таблица описывает состояние v0.8.0. Версия v0.8.1 добавляет локальный SQLite-реестр nonce/IV с отказом при дубликате или недоступности; потоковую обработку основного файла; атомарную публикацию результата; нативный GCM только в файловом CLI; явное разрешение опасного вывода ключей и передачи паролей через argv; пределы PBKDF2; `--aad-file` для EtM. Полный статус и остающиеся риски в [SECURITY_REVIEW_2026.md](SECURITY_REVIEW_2026.md).
