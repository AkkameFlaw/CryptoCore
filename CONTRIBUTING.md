# Вклад в CryptoCore

1. Создайте отдельную ветку `feature/...` или `fix/...`; не переписывайте криптографические алгоритмы без обсуждения совместимости.
2. При изменении публичной функции обновите docstring и docs/API.md.
3. Для исправления безопасности добавьте негативный тест и тест известного ответа.
4. Установите зависимости: `pip install -e ".[dev]"`.
5. Запустите `python tests/run_tests.py --enforce-coverage` и по возможности совместимость OpenSSL; приложите вывод.
6. Не добавляйте ключи, пароли, большие тестовые файлы и результаты с приватными данными в Git.
7. Подготовьте Pull Request с описанием изменений, рисков, тестов и изменений формата файлов.

Долгие benchmarks (PBKDF2 1M и >1 ГБ) выполняются отдельно, результаты сохраняются в docs.
